# 🕹️ HARISH KUMAR — Funky Retro Portfolio

A neon-soaked, animation-dense, retro-vibes portfolio built with React + Three.js + Framer Motion.

## Features
- 3D animated hero with spinning wireframe geometry
- Particle background with interactive repulse
- Retro scanline & CRT effects
- Custom rainbow cursor trail
- Tic-Tac-Toe with unbeatable AI (minimax)
- Snake game with neon graphics
- RPG-style level banners & character stats
- Movie-style credits roll
- Fully responsive

## Run Locally
```bash
cd harish-portfolio
npm install
npm run dev
```

## Deploy to GitHub Pages
1. Create a GitHub repo named `harish-portfolio`
2. Push this code to `main` branch
3. Go to repo Settings → Pages → Source: GitHub Actions
4. The workflow will auto-deploy on push

Or manually:
```bash
npm run deploy
```

## Tech Stack
React, Vite, Three.js, React Three Fiber, Framer Motion, tsparticles
